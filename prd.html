地貌删减线·动态生成系统

把「一个人走过的路」与「他没走的路」编译成一条可逐帧渲染的地形飞行：主线是山脊，岔路是短暂隆起又消失的支脉，消失之后留下永久疤痕。 本文定义这套系统的产品行为、数据契约与验收口径，不定义具体渲染实现。

01背景与问题

人物类短片长期依赖两种表达：一是编年史式的素材堆叠，二是 K 线式的数据可视化。前者讲不出「如果」，后者只能表达涨跌，无法表达质地——同样是错过，有的是缓坡上的绕行，有的是悬崖边的失足。

「地貌删减线」要解决的是第三种表达：把人生选择的空间性可视化。主线沿山脊推进；每到关键节点，地形在分叉处分蘖出另一条短命的支脉，代表那条没走的路；支脉按预设方式消失（雾化、风沙、塌陷、被覆盖），消失后在地表留下浅色疤痕。观众看到的不是结论，而是一个被反复删改过的地形。

现状与缺口

  • 渲染能力不是瓶颈：噪声地形、等高线、体积雾、粒子消散都有成熟实现。
  • 真正的瓶颈在数据层：没有任何公开数据库记录「一个人未选择的路」以及那条路的地形倾向。
  • 因此本产品的核心不是特效，而是一套让叙事判断可以被记录、复用、编译的数据结构与规则库。
系统的壁垒在标注质量，不在渲染。技术管线是通用的，而「那条没走的路在地形上留下什么质感的疤痕」需要每部片子单独做叙事设计。

02目标

以下是可观察的结果，不是感受性描述。凡涉及数值的，均为 v0.1 的目标口径。

#目标可观察判据

03范围

P0 · 一条完整链路必须跑通

  • 单人物、单主线、5–8 个关键节点，其中 3–5 个构成分叉。
  • 四类消失模式（雾化、风沙、塌陷、被覆盖）与疤痕层，疤痕在编译期预烘焙。
  • 相机沿主线样条推进，分叉使用编译期固定的预设计机位，累积疤痕段减速与回望。
  • 文字层：节点信息与「未走之路」标注，与镜头同帧出现，不是后期字幕。
  • 帧号驱动渲染，逐帧导出为图片序列，再合成为 60–90 秒成片。
  • 人工裁定节点：机器只能产出候选，不能直接进入成片。

P1 · P0 稳定后再做

  • 从传记文本批量生成候选三元组，辅助标注。
  • 元素库的可视化管理（预设的增删改与版本发布）。
  • 同一份时间轴指令导出为 DCC 可读格式，供高画质精渲。
  • 多人物批量出片与统一片头片尾。

明确不做

  • 交互式分支浏览：本产品输出的是视频，不是让观众自己选路的页面。
  • 真实地理数据叠加：地形是隐喻，不绑定真实经纬度。
  • 自动生成叙事文案：「未走之路」的一句话描述必须由人写。
  • 自动配乐、配音、发布分发：属于下游环节。

范围取舍的理由：P0 只保证「一份数据 → 一条能看的片子」这条最短闭环成立；任何不服务这条闭环的能力都推迟。

层间契约

边界只允许传递禁止
L1 → L3已锁定状态的节点记录，字段齐全渲染层直接读取资料库；未裁定节点进入编译
L2 → L3预设标识 + 版本号在编排层内联写死地形参数
L3 → L4绝对时间 + 动作 + 目标节点 + 预设引用渲染层自行决定分叉时机或时长
L4 → 成片按指令顺序渲染的帧序列运行时随机数（必须由种子派生）

这条契约对应一个常见的失败模式：特效参数散落在各处，导致每条片子都要重新调参，无法量产。把参数收进元素库，把时间收进编排层，渲染层就退化成一个可替换的执行器——这也是后续能换 DCC 管线的原因。

05功能需求

FR-01人物资料库：节点与删减分支

目的

让「未走之路」成为一条有结构、可审核、可编译的记录，而不是散落在脚本里的旁白。

触发

标注员新建人物条目，或从知识库导入骨架后开始补全。

处理规则

  • 系统按公开知识库导入基础三元组（出生、教育、职业、主要事件），生成草稿节点。
  • 系统可从传记文本抽取候选事件，但只能标记为候选，并在界面上与人工录入区分显示。
  • 每个节点必须补齐三件事才能提交：主线选择、未走之路的一句话描述、那条路的地形倾向。
  • alternate_terrain 只接受三个枚举：坦途 险路 未知。允许在此之外附加坡度/粗糙度倾向作为细化，但不作为必填。
  • disappearance_mode 只接受四个枚举：雾化 风沙 塌陷 被覆盖。
  • 节点必须处于已锁定状态才允许进入编排编译；锁定动作由人工执行，且记录执行人。

结果与状态

保存后节点进入资料库，状态为草稿或候选。锁定后该节点的叙事字段不可直接编辑，修改需先解锁并留下修改记录。

FR-02视频元素库：地形与消失的映射

目的

把「这条路有多难」「这段记忆怎么没的」变成可复用、可版本化、可批量替换的预设，避免每条片子重新调参。

处理规则

  • 元素库分三类预设：地形预设（基底噪声、坡度、断裂密度）、消失预设（机制、时长、透明度/位移曲线）、疤痕预设（颜色、宽度、法线扰动强度）。
  • 语义到参数的方向映射是固定的（见 06.2），预设只负责具体数值与视觉风格。
  • 预设一旦被某条成片引用，其修改必须生成新版本；已锁定的成片继续引用旧版本。禁止原地覆盖已被引用的预设。
  • 同一人物使用固定种子，保证其地貌可复现；种子属于成片配置，不属于预设。
  • 预设一律不可变：修改即生成新版本，不提供原地编辑已发布预设的入口。

叙事原型（第三类资产）

参数可复用，判断不可复用。原型库把「这段岔路怎么演」固化下来：一条岔路引用一个原型，再按需覆盖个别字段，避免每条片子从零编排。

原型适用岔路地形倾向消失机位停留
逃离型主动离开既有轨道险路塌陷侧视 + 拉远2.0s
被驯化型留下、妥协、接受安排坦途被覆盖俯视3.0s
侥幸型偶然撞上的岔路未知雾化平视侧移2.0s
迟到的回头多年后才补上的选择险路风沙回望4.0s

原型只提供默认组合，节点字段优先；冲突时以节点为准，并在编译报告中标注被覆盖的字段。

结果与状态

预设状态为草稿或已发布。只有已发布预设可被编排层引用。已发布预设被引用后，其版本号冻结。

例外

  • 引用的预设被删除时，引用该预设的成片进入「待修复」，并在编译时报出节点与预设标识。
  • 预设时长超过支线可用时长时，以节点间隔为准裁剪，不延长镜头。
FR-03编排层：把节点编译成时间轴

目的

把节点序列翻译成一条逐帧确定的指令流，让渲染层不需要理解叙事，也让同一输入可以重复产出同一结果。

触发

用户在已锁定的节点集合上执行「编译」。编译不产生画面，只产生指令时间轴。

处理规则

  • 编译前校验：所有节点为已锁定、必填字段齐全、引用的预设均为已发布。任一不满足即中断，并列出节点标识与缺失项，不产出半成品时间轴。
  • 主线总时长由节点数量与镜头节奏系数决定，目标 60–90 秒；超出时不自动压缩，提示拆分或删减节点。
  • 分叉节点生成一组固定动作：fork_begin（支线地形出现 + 相机侧移拉远）→ branch_live（支线存续）→ branch_dissolve（按消失预设执行）→ scar_commit（疤痕写入持久层）。
  • 支线存续期默认为 2–4 秒，具体值按节点间隔自适应；存续期不得与前一分叉的动作窗口重叠。
  • 相机在主线段使用样条推进；分叉处使用该分叉的预设计机位——每个分叉预置 2–3 个候选，编译期校验不穿模后固定一个，运行时不搜索样条变体。疤痕累积段降速，疤痕强度最高档的节点之后插入回望。
  • 文字指令与镜头同批生成，文字出现帧与 fork_begin 对齐，时长在编译期固定。
  • 同一节点重复编译必须得到相同指令序列（字节一致），时间不得依赖当前系统时间或随机数。

结果与状态

产出时间轴后，成片进入「已编译」。指令流以绝对时间标注每个动作的起止帧，可直接交给渲染层逐帧执行。

FR-04渲染与合成

目的

把时间轴变成画面。渲染层是可替换的执行器：换实现不换上游数据。

处理规则

  • 渲染层只做三件事：按指令形变地形、按指令移动相机、按指令播放消失特效并写入疤痕。
  • 疤痕在编译期预烘焙为独立记忆层（高度、法线、色），渲染时只按时间混合透明度，不做运行期写入。重渲任意片段，疤痕状态都与从头渲染一致。
  • 渲染由帧号驱动：第 n 帧固定为 t = n / fps，设置时间轴时间、强制渲染、读回像素，不依赖真实时钟，也不依赖帧间状态。
  • 逐帧导出，帧号从 00001 连续递增，帧率在成片配置中固定；中途失败可从最后一帧续渲，续渲结果必须与未中断时一致。
  • 合成阶段只做编码与封装，不改变画面内容；成片规格为 1080p、24 或 30fps、60–90 秒。

结果与状态

成片状态依次为：待编译 → 已编译 → 渲染中 → 已合成。渲染中断保留已完成帧并标记断点；合成失败可仅重跑合成，不重渲帧。

两条实现路线（同一上游，选择权在下游）

维度Web 渲染管线DCC 渲染管线
定位P0 主力，面向量产与快速迭代P1，面向标杆片精渲

务实策略：用 Web 管线出预览与初稿，同一条时间轴对需要电影级质感的条目再走精渲。两套管线共享上游，不重复劳动。

例外

  • 渲染过程中预设被修改：当前任务继续使用启动时锁定的版本，不热更新。
  • 帧序列缺帧时合成中断并报出首个缺失帧号，不生成带空帧的成片。
FR-05文字层：让画面可被读懂

目的

地形承担情绪，文字承担语义。没有文字层时，观众看到的只是一段地形形变；有了节点信息与「未走之路」的并行标注，删减才可被识别。文字属于时间轴，不是后期字幕。

触发

编排层编译时为每个节点生成文字指令，与镜头同批产出、同批锁定。

处理规则

  • 节点进入画面时显示：年份与年龄、节点名、主线一句话。
  • 分叉节点的「未走之路」与 fork_begin 同帧出现，与支线共存亡；支线消失后文字淡出，不常驻。
  • 疤痕段不显示长篇文字，仅在回望镜头中短暂复现节点名，作为记忆索引。
  • 文字固定在安全区（默认左下），不得覆盖分叉区域；分叉侧视时安全区随镜头切换。
  • 文字停留时长不短于 2 秒，且不短于该节点镜头时长的 40%，保证可读完。

结果与状态

文字指令随成片配置一同锁定；改文案即视为输入变化，必须重新编译时间轴。

例外

  • alternate_path 超过 32 字时最多折两行，仍超出则阻断编译并提示改写。
  • 无岔路节点不显示「未走」行，只保留主线文字。
  • 文字早于 fork_begin 出现视为缺陷，不允许先剧透再出现地形。
FR-06主线光点与结尾根系

目的

让「走过的主线」本身可见，并在结尾把散落的删减收束成一张可读的地形记忆。这是把「地貌」从背景变成叙述者的关键。

处理规则

  • 光点贴地推进，高度随地表起伏；已走过的路径整条发亮，作为画面中唯一发亮的河道。
  • 推进节奏按坡度加权：越陡越慢；断崖类节点处短暂驻留，不做匀速平移。
  • 分叉时支线上出现一个更暗、更冷的对照光点，与支线同生同灭；主线光点不进入支线。
  • 支线消失后，对照光点的路径降为贴地暗线，与疤痕一起构成「根系」。
  • 结尾固定插入拉远镜头：相机升高并后退，视野覆盖全片主线，时长 6–10 秒。
  • 结尾镜头只做空间收束，不新增信息；文字只保留一句总结。

结果与状态

光点进度与结尾镜头都属于时间轴，参与确定性校验；跳段重渲时位置必须一致。

例外

  • 地形不足以容纳全片视野时，允许抬高相机并放宽视角，但不得穿入地形。
  • 光点在节点处驻留过长时，压缩下一段推进，不顺延分叉窗口。

06共享规则

6.1 状态

节点状态

草稿→ 候选→ 已裁定→ 已锁定

只有「已锁定」参与编译；「已裁定」可编辑；任何状态都可退回草稿，退回时清空锁定人记录。机器抽取只能产生「候选」，不能跳到「已裁定」。

成片状态

待编译→ 已编译→ 渲染中→ 已合成

「渲染中」可因中断回落到「已编译」并保留断点帧号；已合成后修改任一锁定节点，成片转为「待编译」，旧成片文件保留不覆盖。

6.2 地形语义映射

语义决定方向，预设决定数值。以下为方向的固定约定，数值区间为占位默认值。

语义影响参数方向约定
阻力该段主线坡度越大越陡，等高线越密
消耗地表粗糙度、噪声倍频越大越碎，细节越密
转折断裂线密度、断崖高差转折越强，断崖越多
停滞起伏幅度、等高线间距越停滞越平缓稀疏
坦途支线坡度、表面断裂低坡度、低粗糙、路径连续；用平顶台地拉开轮廓，避免与主脊混在一起
险路支线坡度、断裂密度高坡度、高断裂、边缘锐利
未知坡度、能见度中等坡度、强表面噪声、能见度低，轮廓不可读

分叉地形的生成方式：以分叉点为圆心、向支线方向辐射有限半径，对主线高度场做局部二分，支线剖面按上表参数生成。支线不单独建模，避免与主线拼接出现裂缝。

6.3 消失模式与疤痕

模式机制默认时长结束形态
雾化透明度衰减 + 体积雾包裹[A] 3.0s地形归零，留浅色轮廓线
风沙粒子沿坡面剥离，顶点轻微抖动[A] 3.0s残留散点与磨圆边缘
塌陷高度场下沉，边缘拉裂[A] 2.5s凹槽，两侧留断裂壁
被覆盖新地表覆盖旧地形（植被/沉积）[A] 4.0s浅色贴花，纹理差异可见

疤痕规则：四种模式结束后都落入疤痕层，不做例外。疤痕强度取值为 1–3，对应贴花透明度三档，默认 0.15 / 0.30 / 0.45 [A]。疤痕在编译期一次性预烘焙成记忆层，渲染时按 scar_commit 的绝对时间切换可见性，运行期只读不写；同一分叉点重复编译不得叠加多层疤痕，重渲任意片段结果一致。

6.4 相机规则

条件行为
常规推进沿主线样条，速度按节点间距自适应
视觉风格赛博全息：深蓝底、青色等高线能量环、冷紫岩壁、世界坐标网格；主线与光点强制暖金色，靠冷暖对比把「唯一的路」从地貌里拎出来
粒子1400 颗悬浮尘埃（上升 + 闪烁）铺满空间，220 颗金色火星绕光点旋转上升；全部由 t 推导，不引入随机状态
背景音乐单轨背景乐，随播放头起停：播放即起、暂停即停、拖动后按新时间点续播；默认音量 0.42，可一键静音。成片由 ffmpeg 与帧序列混流，不参与逐帧确定性校验
数值→高度映射value 归一化区间取 74–140（V_MIN=74, V_SPAN=66），高度 = 3 + 46×norm + 噪声扰动；即 100 分的人生对应约 22 单位，±40 的变化就能造出 25 单位以上的落差，峰谷差可达 45 单位，用于制造「巨变」的视觉冲击
机位高度与焦段分叉窗口用预设计机位：离地 6–12 单位、视角 40°；|delta| ≥ 40 的巨变节点改用 plunge 机位——站在跌落起点，高出当地地表 30 单位俯看整段落差。高度按当地地表相对计算，峰顶与谷底获得同样的构图
POV 视点主线推进时切第一人称：相机置于光点后方约 13 单位、离地 3.2 单位，注视前方 21 单位的路径点，视角 66°，带 0.12 单位呼吸浮动；分叉窗口前后 0.5 秒用平滑权重退回预设计机位，结尾拉远强制回第三人称
进入分叉从该分叉预置的 2–3 个机位中固定一个，通常侧移 15°–25° 并拉远至 1.2 倍，使两条地形同时入画；机位在编译期校验不穿模，运行时不改
疤痕累积段速度降至 0.6 倍
疤痕强度为 3 的节点之后插入一次短暂回望，回望时疤痕必须在画面内
全程约束相机与地表保持最小间距，不得穿入地形；无可行解时抬高相机而非穿模

6.5 可复现性

  • 地形随机性全部由成片种子派生，禁止运行时取系统随机数或系统时间。
  • 渲染按帧号推进：第 n 帧对应固定时间，暂停、续渲、跳段都不能改变该帧内容。
  • 同一人物使用固定种子，因此同一人物的地貌在多次成片中保持同一张脸。
  • 相同数据 + 相同种子 + 相同帧率，两次导出的对应帧必须一致；容器层面的编码差异不算违反。
  • 元素库预设的版本号参与确定性校验：版本变化即视为输入变化。

6.6 命名与引用

  • 节点标识全片唯一，形如 N01；跨片复用同一人物时以人物标识前缀区分。
  • 时间轴指令必须携带目标节点标识与预设标识，不允许只写绝对帧号而无归属。
  • 字幕、编译报告、验收记录统一使用节点标识，不使用序号描述（如「第五个点」）。

08异常与边界

场景系统行为
节点未锁定即编译阻断编译，列出未锁定节点标识
缺少未走之路描述视为无岔路节点，编译通过但报告中单独列出
地形或消失枚举值非法阻断，指向具体字段与节点
年份或年龄不单调阻断提交，提示冲突节点对
分叉过密导致动作重叠按节点间隔压缩支线存续期，报告中被压缩的节点
总时长超出 90 秒不自动压缩，提示拆分或删减节点
引用预设被删除成片转「待修复」，编译报出节点与预设标识
渲染中断保留已完成帧，从最后一帧续渲，不整条重跑
帧序列缺帧合成中断并报出首个缺失帧号，不产出带空帧的成片
疤痕被后续镜头遮挡视为缺陷：回望镜头必须能看见疤痕，否则调整相机而非移除疤痕
「未走之路」文案超长最多折两行；仍超长则阻断编译，提示改写文案
叙事授权未确认阻断编译、不出片。这是硬门禁，不走「先出片后补授权」

09验收标准

以下条目用于判定 P0 是否达成。除 AC-11 为主观试映项外，其余均可由导出物或编译报告直接核验。

  1. 使用基线 8 节点数据编译，输出时间轴且无缺字段、无未锁定节点，编译报告为空错误。
  2. 同一种子连续编译两次，指令序列完全一致；采用帧号驱动后，同一帧在整片渲染与跳段重渲两条路径下画面一致。
  3. 6 个分叉各自在 fork_begin 起 0.5 秒内，两条地形的坡度或断裂差异在画面上可辨认。
  4. 四种消失模式各至少出现一次，均按预设时长完成，过程中不出现跳帧式突变或地形闪烁。
  5. 每个分叉结束后，疤痕在后续 5 秒内持续可见；疤痕强度为 3 的节点后存在可辨认的回望镜头。
  6. 从任意中间帧开始重渲一段，疤痕的可见性、位置与从头渲染完全一致，验证记忆层预烘焙。
  7. 每个分叉的「未走之路」文字与 fork_begin 出现在同一帧，且文字区域不遮挡两条地形的轮廓。
  8. 全片相机穿入地形帧数为 0；相机与地表最小间距不触发约束告警。
  9. 成片为 1080p、24 或 30fps、时长 60–90 秒，可正常播放且首尾无黑帧残留。
  10. 替换人物数据与种子、不改任何代码，可产出结构完整的第二条片子。
  11. 修改一个已被引用的元素库预设，不改变已锁定成片的既有画面；新版本仅对新编译生效。
  12. 构造一份缺字段数据，系统阻断编译并准确指出节点标识与缺失字段，不生成半成品时间轴。
  13. 面向未看过说明的观众试映，多数人能指出片中至少两处「被删掉的路」；此项记录结果，不作硬性通过线 [TBD]。

10开放问题

叙事授权与史实边界
涉及真实公众人物时，对「未走之路」的假设性描述需要什么程度的依据与授权？是否只做已故人物、是否需要家属沟通、争议节点是否要标注「此为推演」。该项已升级为编译前置门禁：口径未确认的人物不进入编译，系统层面不允许「先出片后补授权」。
数据源许可与署名
骨架数据来源的许可条款决定成片是否可商用、是否必须署名。当前按可自由使用的知识库设计，但未逐项核对。
成片规格口径
60–90 秒、1080p、30fps 为占位目标。若用于竖屏分发，构图、相机侧移幅度、字幕位置都需要另一套规则，不能简单裁切。
支线存续时长的依据
2–4 秒来自「够看清差异、又不打断主线」的经验判断，未做观众测试。若试映显示观众来不及辨认，需要上调并相应增加全片时长。
元素库的沉淀标准
什么情况下一种消失方式值得沉淀为预设，而不是每条片子单独设计？如果预设过粗，片子会同质化；过细则等于没有复用。这是量产能否成立的关键决策。
非公众人物的适用性
普通人物没有公开节点数据，也没有可核对的事实，系统是否仍成立？若成立，叙事判断的权重会进一步上升，可能需要另一套录入形态。
